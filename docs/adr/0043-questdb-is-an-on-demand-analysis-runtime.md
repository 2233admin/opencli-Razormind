# QuestDB is an on-demand analysis runtime

QuestDB may back a Data Analysis Plugin as an optional External Analysis Runtime for user-requested Analysis Snapshots, but PostgreSQL or SQLite remains authoritative. The first release exports only redacted Workflow Trace events and acquisition execution metrics from a completed, explicitly selected range, retains snapshots for 30 days by default, and records an audit receipt in OpenCLI; it does not dual-write, subscribe to the event spine, retry in the background, or export raw payloads. Findings may produce Agent Operation Proposals, while every action continues through the existing confirmation, Gate, Actuator, and evidence path.
